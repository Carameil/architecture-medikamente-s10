# Справочник проекта: Medikamente

## О компании (As-Is)

**Структура:**
- 1 офис, планируется расширение (филиалы)
- 20 административных сотрудников + 15 медицинских специалистов

**Отделы:**
| Отдел | Кол-во | Функции |
|-------|--------|---------|
| Медицинские специалисты | 15 | Оказание услуг |
| Ресепшен | 3 | Журнал записей, клиентские контракты |
| Кассиры | 3 | Приём платежей, учёт в Excel и 1C |
| Бухгалтерия | 3 | Процессинг платежей, кадры, зарплаты, налоги |
| Склад | 3 | Учёт ТМЦ, закупки оборудования |
| IT-отдел | 3 | Тех.директор, админ сети, бизнес-аналитик |

**Текущий стек:**
- Excel, Outlook, 1С (файловый режим)
- 1С:Бухгалтерия предприятия
- 1С:Торговля и склад
- Windows Server 2022 (AD, DNS, DHCP, LDAP, файловый сервер, Exchange)
- ККМ через TCP/IP + OLE компонент 1С

**Проблемы:**
- Всё вручную (Excel, сканы, PDF, JPG)
- Нет аудита действий
- Нет контроля потоков данных
- Только доменная аутентификация
- Не соответствует требованиям РФ по работе с PII

---

## Цели бизнеса (To-Be)

1. **Конфиденциальность, целостность, доступность данных** — приоритет
2. **Интеграция лаборатории анализов с API**
3. **BI/ML/AI сервисы** — озеро данных
4. **Новые системы:**
   - Портал для клиентов
   - Портал для ресепшена
   - Платёжный шлюз
   - CRM
   - Интеграция с лабораторией

**MVP (через пару месяцев):**
- Самостоятельная запись клиента на приём через портал
- Ресепшен видит записи
- Напоминания за день до приёма
- Категоризация данных по доменам
- RBAC/ABAC для доступа

**Финальное состояние (через год):**
- Полная автоматизация записи (портал + мобильное приложение)
- Push-уведомления / голосовой робот
- ЛК пациента (только свои данные)
- Тегирование данных
- Аудит доступа
- Мониторинг и алертинг

**НФТ:**
- Безопасность (конфиденциальность)
- Масштабируемость (5x рост)
- Сопровождаемость
- Конфигурируемость

## Ключевые принципы

- **Privacy by Design** — конфиденциальность по умолчанию
- **Data Minimization** — минимизация данных
- **Data Lineage** — отслеживание происхождения данных
- **RBAC/ABAC** — контроль доступа
- **Encryption at Rest & In Transit** — шифрование данных
